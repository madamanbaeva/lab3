# lab3

## Назначение
Учебный репозиторий для лабораторной работы по работе с ветками в Git. В нём создаётся простая веб-страница (index.html, стили и скрипт) с использованием веток main, develop и feature.
lab3
## Настройка разработки
1. Установить Git и Visual Studio Code.
2. Клонировать репозиторий: `git clone https://github.com/madamanbaeva/lab3.git`
3. Перейти в папку проекта и перейти на ветку develop: `git switch develop`
4. Отключить быструю перемотку слияния:
   - `git config branch.main.mergeoptions "--no-ff"`
   - `git config branch.develop.mergeoptions "--no-ff"`
